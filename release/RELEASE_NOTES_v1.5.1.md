# Bridgistic v1.5.1

## Namespace-corrective patch release

Bridgistic v1.5.1 republishes the free-only MCP server with the exact WordPressistic-owned MCP Registry namespace. This patch is required because npm package versions are immutable and v1.5.0 was published before the namespace metadata was corrected.

There are no functional feature changes from v1.5.0. The free WordPress plugin and MCP packages continue to lock premium WPistic/SaaS features and ship the secure bridge features available in the free edition.

## Distribution

- npm package: `bridgistic-mcp-server@1.5.1`
- MCP Registry name: `io.github.Wordpressistic/bridgistic`
- GitHub repository: `https://github.com/Wordpressistic/bridgistic-claude-marketplace`
- WordPress, Claude, desktop, and OpenAI packages are rebuilt from the same versioned source.
