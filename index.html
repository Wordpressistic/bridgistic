Live in 3 minutes

No terminal required for Claude Desktop. The setup wizard generates every config for every AI client.

Install the plugin

Upload the zip via Plugins → Add New → Upload and activate.

bridgistic-wordpress-plugin-1.3.1.zip

Mint a key

Open Bridgistic → AI / MCP Connections, pick your client and a permission preset (start read-only). The secret is shown once.

Connect your AI

Double-click the generated desktop extension, or paste the generated config into Claude Code, Codex, Gemini or Cursor.
