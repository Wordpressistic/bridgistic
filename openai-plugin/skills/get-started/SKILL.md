# Get started with Bridgistic

Bridgistic connects an MCP client to WordPress through a dedicated, scoped
connection. It does not require sharing a WordPress administrator password.

Before using the connection:

1. Install the free Bridgistic plugin from the official WordPress plugin
   release at https://github.com/wordpressistic/bridgistic/releases/latest.
2. In WordPress, open Bridgistic → AI / MCP Connections and create a
   read-only key first.
3. Complete the connection approval in WordPress when ChatGPT or Codex opens
   the Bridgistic authorization flow.
4. Start with a read-only inspection. Ask for approval before any write or
   destructive operation.

The free plugin includes scoped HMAC access, approvals, audit logs, snapshots,
manual playbooks and limited scheduling. Premium SaaS features are not
available in this public plugin.
